## 授权判定

- 规则（机械执行，无人工放行）：
  - `authorDeathYear === null` → 视为公版（上古/佚名）；但作品若属于「民國/現代/當代」分类，一律剔除。
  - `authorDeathYear + 50 < 2026` → 公版。
  - `authorDeathYear > 1975` → 一律剔除（1976 年卒要到 2026-12-31 才到期）。
- 作者来源：作品页 `wikibase_item` → Wikidata `P50` → 作者 `P570`；没有 `P50` 时从页面 header 模板读 `author`/`translator`，再查 `Author:` 页面的 `wikibase_item` → `P570`。
- `bytes` 为 MediaWiki 页面 `length`（wikitext 字节）：多章作品按章累加（最多 200 章），单页作品取根页面。

## 怎么复现

```bash
# 1. 采集（断点续跑；中间结果在 seed/.cache/，可随时中断重来）
node scripts/seed/harvest.mjs

# 2. 只校验清单（不发网络请求）
node scripts/seed/harvest.mjs --validate-only
```

环境：Node 24，零第三方依赖。脚本对 `zh.wikisource.org/w/api.php` 与 `www.wikidata.org/w/api.php`
单并发请求，间隔默认 1500ms（可调，下限 150ms），失败重试 3 次（指数退避），
429 按 `Retry-After` 等待；分类/页面超时或失败会跳过并计入上表，不会中断整体采集。
每次 API 响应都落到 `seed/.cache/api/<sha1>.json`，重跑时直接复用，所以断点续跑不会重复打接口。

## 已知取舍

- 本清单按「整本」契约生成：`page` 是维基文库根页面，`chapters` 是它的子页面列表（单页作品为 `[page]`）。仓库若另有「卷级」清单，可用 `SEED_CATALOG=...` 指定，不要与本清单互相覆盖。

- `catalog.json` 在 README 契约字段之外多写了一个 `sourceCategories`（数组），因为「任一来源分类 ≤ 300 条」需要可机读的来源归属；其余字段与契约一致。
- 多章作品的章节来自根页面里链接到的 `根页面/子页面`。如果根页面没有列出目录（部分佛经只有子页面），该作品会被当成单页作品；正文不足 20 KB 的会自动剔除，不会误收。
- 章节数超过 200 的作品按 README 的 build-epub 上限截断（只保留前 200 章），`bytes` 也按这 200 章累计。
- 作者在 Wikidata 没有 `P50` 或没有 `P570` 时，`authorDeathYear` 写 `null`，按「上古/佚名」处理，`licenseNote` 写明依据。
- 少数四部丛刊/正史卷页是重定向页或嵌入（transclusion）页，`prop=info` 的 `length` 只算这些「壳页」的 wikitext，因此多章作品的 `bytes` 可能明显小于渲染后正文；build-epub 走 `action=parse` 会展开嵌入/跟随重定向，实际 EPUB 更大。单页作品的 `bytes` 就是该页本身，不受此影响。
