# webooks —— 公共电子书库
#
# 这个文件本身就是一次「请求预算」优化，理由值得写下来：
#
#   首页上有一个「进入书柜」链接指向 /dav/，而 /dav/ 是一棵**可以被无限枚举**
#   的目录树 —— 每翻开一层目录是一次 Worker 请求，每一本书的下载又是一次。
#   没有 robots.txt 时，爬虫（以及各种顺藤摸瓜的抓取脚本）会从首页顺着目录
#   把整个书库翻一遍：几万本书就是几万次请求，免费层的 100,000 次/天
#   很可能被一次爬取就吃掉一大块。
#
#   HTML 浏览页上已经有 <meta name="robots" content="noindex">，
#   但 noindex 只阻止**收录**，**不阻止抓取** —— 抓取照样花请求。
#   真正能把请求省下来的是这里的 Disallow。
#
# 书库本身是希望被找到的，所以首页与求书墙保持开放。

User-agent: *

# WebDAV 目录树：可无限枚举，最贵的一条
Disallow: /dav/

# 接口：给页面用的 JSON，没有让爬虫抓的理由
Disallow: /api/

# 管理后台
Disallow: /admin

# 上面是「禁止」，下面是「明确允许」，避免过于宽泛的 Disallow 误伤
Allow: /
Allow: /requests
