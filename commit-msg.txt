fix(probe): 区分「Worker 崩溃」与「边缘拦截」，不再误判

线上部署后所有路由返回 500 / error code 1101，但探针却报
「极可能是被 Cloudflare 边缘拦截」—— 这是误判，会把人引向错误方向。

修正后：
- /health（不碰 D1、不碰任何绑定）作为预检，Worker 本身不通就立刻停止，
  不再对着一堆注定失败的 WebDAV 检查报 26 条红
- 新增 classifyFailure()：5xx + Cloudflare 错误码 -> worker-crash；
  403/405 且无 Worker 标记 -> edge-block；其余 -> unknown（如实报告，不猜）
- 识别 1101 的两种响应形态：纯文本 error code: 1101，以及 HTML
  span.cf-error-code 里的 1101（curl 拿到前者，fetch 拿到后者）

判别依据：边缘拦截只影响 PROPFIND/MKCOL 等自定义动词，不会让 GET/OPTIONS
也失败，且边缘页是 HTML/403，不会是 1101。1101 说明请求已到达 Worker。
